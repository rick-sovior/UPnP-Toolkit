2. SERVER.PY (Credential Harvester) – FULL REPORT
================================================================================

FILE NAME      : server.py
VERSION        : Professional v2.0
LANGUAGE       : Python 3.6+
DEPENDENCIES   : None (uses only Python standard library)

2.1 NEW FEATURES & IMPROVEMENTS
-------------------------------
1. Multi-Threaded Server
   - Uses ThreadingHTTPServer instead of the basic HTTPServer.
   - Handles hundreds of simultaneous victim connections without blocking.

2. Dynamic Port Binding
   - Old version: Hardcoded to port 80 (required root).
   - New version: Configurable via -p (default: 8080). Can run as a normal user.

3. Structured Logging
   - Credentials are written to credentials.log with timestamps.
   - Logs include the victim's source IP address.
   - Console output remains clean (only warnings and captures shown).

4. Custom HTML Support
   - Old version: Facebook-style HTML was hardcoded inside the script.
   - New version: Supports --html FILE to load any custom login page.

5. Full Argparse CLI
   - Arguments: -H (host), -p (port), -l (log-file), --html (custom HTML).
   - Auto-generated --help menu.

6. Smart IPv4 Detection
   - Automatically detects the primary IP address of the default network interface
     (get_default_ip()) to show the correct server URL.

7. Robust Error Handling
   - Handles empty POST bodies (400), malformed requests, permission errors,
     and port conflicts gracefully.
   - Returns proper HTTP status codes (404, 400, 500) instead of crashing.

2.2 COMMAND-LINE USAGE
----------------------
python3 server.py                 # Start on default IP, port 8080
python3 server.py -p 80           # Run on port 80 (needs root)
sudo python3 server.py --html mypage.html -l secret.log  # Custom page & log

3. HACK.SH (UPnP & MITM Toolkit) – FULL REPORT
================================================================================

FILE NAME      : hack.sh
VERSION        : Professional v2.0
LANGUAGE       : Bash 4+
DEPENDENCIES   : curl, iproute2, miniupnpc, bettercap

3.1 NEW FEATURES & IMPROVEMENTS
-------------------------------
1. Environment Variables & CLI Overrides
   - Old version: 4 hardcoded variables (ROUTER, ATTACKER, VICTIM, SPOOF_DOMAIN).
   - New version: Override via -r, -a, -v, -p or environment variables.
   - No need to edit the script for different targets.

2. Expanded Command Set (13+ commands)
   - Old commands: backdoor, list, delete, hijack.
   - New commands: status, discover, list, add, delete, test-description,
     watch, mitm, dns-hijack, and help.

3. Safety Confirmation (-y / --yes)
   - Dangerous actions (add/delete/watch/mitm) prompt for confirmation.
   - The -y flag bypasses prompts for automated scripting.

4. Robust SOAP Handling
   - Uses a soap_post() function with proper XML generation.
   - Inspects responses for UPnP faults and error codes.
   - Old version: Raw curl with zero error checking.

5. Watch Mode (Automatic Restoration)
   - Command: hack.sh watch.
   - Monitors a specific NAT mapping every 60 seconds.
   - Automatically re-adds the mapping if it disappears.

6. Advanced MITM & DNS Hijack
   - Old version: Only a simple DNS hijack.
   - New version:
     - mitm: Full-duplex ARP spoofing with Bettercap.
     - dns-hijack: Domain-specific spoofing (e.g., *.google.com).
   - Automatically detects the network interface and validates victim/router IPs.

7. Test Description (Safe Input Test)
   - Command: test-description.
   - Sends a harmless description string to test UPnP input handling.
   - Explicitly DOES NOT claim RCE – just tests functionality safely.

8. Persistent Logging
   - Every action is logged to upnp_lab.log with timestamps.
   - Facilitates forensics and troubleshooting.

9. Dependency Validation
   - Checks for required binaries (curl, upnpc, bettercap, ip).
   - Provides clear error messages if dependencies are missing.

3.2 COMMAND-LINE USAGE
----------------------
./hack.sh status                      # Test endpoint & show info
./hack.sh discover                    # Fetch device description XML
./hack.sh list                        # Show current UPnP rules
./hack.sh add 4444 22 192.168.1.7 TCP -y  # Open backdoor
./hack.sh watch 4444 22 192.168.1.7 TCP   # Auto-restore mapping
sudo ./hack.sh mitm 192.168.1.100     # Start ARP MITM
sudo ./hack.sh dns-hijack 192.168.1.100 192.168.1.7 "facebook.com"
./hack.sh help                        # Show full usage
